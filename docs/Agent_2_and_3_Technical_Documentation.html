1. Executive Overview & Pipeline Context

ETRAI processes input documents through a sequential 4-agent verification pipeline. While Agent 1 extracts and truncates raw text, Agent 2 (Claim Extractor) and Agent 3 (Fact Verification Agent) form the core intelligence of the platform:

  • Agent 2 (Claim Extractor): Converts unstructured document text into structured, atomic, and testable factual assertions (max 25 claims).
  • Agent 3 (Fact Verification Agent): Queries live web search indexes, cross-references claims against live search snippets using GPT-4o, validates live HTTP URLs to eliminate 404 links, and detects fabricated news events.

2. Agent 2: Claim Extractor Service

Source File: backend/src/services/claimExtractor.js

2.1 Primary Function & Input Guardrails

Agent 2 receives raw extracted text from Agent 1. To prevent context window overflow and reduce latency, the text is truncated to the first 15,000 characters (~3,750 tokens) before being sent to GPT-4o.

2.2 GPT-4o Execution Strategy & JSON Schema

Agent 2 uses gpt-4o with a low temperature of 0.2 and enforces JSON output using response_format: { type: "json_object" }.

Agent 2 System & User Prompt Structure
"You are Agent 2 (Claim Extractor) in an AI Fact-Checking system.
Your task is to analyze the text below and extract up to 25 of the most important, specific, and verifiable factual claims.
Focus on:
1. Specific quantitative metrics, numbers, percentages, dates, and financial figures.
2. Direct factual assertions regarding events, companies, people, or scientific claims.
3. Statements that can be proven True or False by independent web search.

STRICT RULE: Maximum 25 claims. Do not include opinions or subjective commentary."

2.4 Heuristic Fallback Engine (extractMockClaims)

If OPENAI_API_KEY is unconfigured, missing, or throws an API exception, Agent 2 fails gracefully over to an internal heuristic extraction engine:

  • Splits text into clean sentences using regex lookbehind /(?<=[.?!])\s+/.
  • Filters for sentences between 20 and 250 characters.
  • Matches regex patterns for quantitative terms: /\d+|percent|dollar|company|market|report|announced|according|growth|year|million|billion|increase|decrease|found|proved|stated/i.
  • Extracts up to 25 factual sentences and calculates dynamic importance scores (60–100 range).

3. Agent 3: Fact Verification Agent Service

Source File: backend/src/services/factVerifier.js

3.1 Primary Workflow & Architecture

Agent 3 iterates through every claim extracted by Agent 2 and executes a multi-layered verification strategy combining live web search, AI cross-examination, major event fabrication detection, and HTTP link validation.

3.2 Live Web Search Integration (Serper API)

Agent 3 sends a POST request to the Serper Google Search API (https://google.serper.dev/search) with the claim text as the query payload:

  • Retrieves top 5 organic search results per claim.
  • Extracts title, target URL, text snippet, and cleans domain hostnames (e.g., stripping www.).
  • Maintains a list of trusted domain filters including reuters.com, apnews.com, bbc.com, factcheck.org, snopes.com, bloomberg.com, wsj.com, .gov, and .edu.

3.3 Dual-Engine Verification & Classification Rubric

Retrieved search snippets are passed to gpt-4o (with temperature: 0.0) along with strict classification instructions:

Verdict Status Classification Criteria Default Confidence
Verified Search result snippets directly and explicitly corroborate the claim text. Must cite source titles and pass HTTP link validation. 85% - 98%
False Search snippets directly contradict/refute the claim OR the claim asserts a major public event but zero search coverage exists. 90% - 98%
Suspicious Claim is ambiguous, minor, uncorroborated by search hits, or candidate source links fail live HTTP validation. 50% - 70%

3.4 Major Event Fabrication Detection (isMajorEventAssertion)

Deception Detection Guardrail
If a claim describes a major public news event (such as actions by national leaders, military operations, wars, treaties, or state emergencies) but Serper API returns 0 search results, Agent 3 classifies the claim as FALSE rather than ambiguous.

Regex matching patterns detect high-impact entities and actions:

/\bprime minister\b|\bpresident\b|\bmodi\b|\bbiden\b|\bputin\b|\bxi jinping\b|\bmilitary campaign\b|\bdeclared war\b|\binvaded\b|\bnuclear test\b|\bstate of emergency\b/i

When triggered with 0 search hits, Agent 3 attaches the standardized reasoning:

"This claim describes an event of major significance with no corroborating coverage found across searched sources, which is strong evidence of fabrication."

3.5 Live Source HTTP URL Validator (validateSourceUrl)

To eliminate dead or broken links from final reports, candidate URLs selected by GPT-4o are dynamically checked:

  • Executes a live HTTP GET request with an AbortController timeout of 4,000 ms.
  • Includes standard browser User-Agent headers to avoid false bot rejections.
  • Rejects any URL returning status 404 Not Found or connection timeouts.
  • Safety Fallback: If a claim was labeled Verified but all supporting URLs fail validation, its status is downgraded to Suspicious (or False if major event).
